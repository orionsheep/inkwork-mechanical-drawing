# 原理速查：为什么这样就能出工程图

> 完整版在工程里的 `docs/GUIDE.md`。这里是给 agent 看的压缩版——**看完这页就够动手了**。

## 一条流水线

```
零件表 + 几何 ──▶ three.js 场景（真几何，每个零件挂"墨水材质"）
                        │
        ┌───── InkRenderer 多通道渲染 ─────┐
        │ pass0 颜色/明暗   pass1 法线+零件ID  (剖视用裁剪面)  │
        │ (三视图时) pass2/3 深度剥离 → 被遮挡的轮廓            │
        └──────────────┬──────────────┘
                       ▼
   合成着色器：从 法线/深度/零件ID 的**不连续处**提炼线
   → 按模式画成：铅笔线稿 / 工程图（粗实线·虚线·剖面线·点画线）
                       ▼
   叠 DOM/SVG：编号气泡引线、三视图投影连线、标题栏、明细表
```

关键文件：`src/scene/ink.ts`（着色器）、`InkRenderer.tsx`（多通道/深度剥离）、
`Part.tsx`（零件节点）、`geometry.ts`（几何缓存）、`src/drawing/layout.ts`（三视图）、`explode.ts`（分层拆解）。

## 1. 线是怎么"提取"出来的

对每个像素问：**邻居的 深度 / 法线 / 零件ID 和我差得多吗？差得多 → 这里是一条线。**

| 不连续 | 得到 |
|---|---|
| 深度突变 | 物体轮廓、前后层交界 → **粗实线（可见轮廓）** |
| **零件 ID 突变** | **两个零件之间的分界线** |
| 法线突变 | 折角边缘 → 细线（折线） |

`edgeAt()` 在 8 个方向采样，轮廓再补一圈 1.45 倍半径的重描，所以外轮廓比折线粗。
侧对镜头的斜面会自动抬高阈值，避免刷成一团黑。

> **推论**：`<Part>` 的 `index` 写进 ID 通道。一组几何归到一个零件内部就没有分界线；
> 分到两个零件，零件之间就自动长出轮廓线。**"装配图每个零件轮廓分明"是白送的。**

几何都过了 `toCreasedNormals(π/5)`：硬边保持尖锐（有折线），圆面保持平滑（没杂线）。

## 2. 剖视为什么自动正确

不是"切个 2D 图"，而是**用一个裁剪平面真的把 3D 模型切掉一半**：

- `SECTION_PLANE = Plane((0,0,-1), 100)`：法线朝 −z → **切掉 z > 0（朝镜头）那半**；
- 每个网格都有带裁剪的材质，`InkRenderer` 在剖视时把 `constant` 从远处扫到 0；
- 被切开的**背面**（`!gl_FrontFacing`）识别为"切口"，涂 `uCut` 色，并把 ID 偏移半个单位让切口轮廓更清晰；
- 合成阶段给切口画 **45° 细实线剖面线**，**相邻零件方向相反**（按零件 index 奇偶取 45°/135°）——国标要求。

**所以剖视要正确只有两条**：
1. 内部结构**真的建出来**（空心的要挖空）；
2. 剖切面固定在 **z = 0**，想让谁被剖到就摆成关于 z=0 对称。

## 3. 三视图（第一角）

4 部正交相机（主/俯/左/正等轴测）把同一场景各渲一次，按第一角摆放：

```
    主视图(front)    左视图(left)
       ────────        ────────
    俯视图(top)      正等轴测图(iso)
```

四视图**同一比例** → 屏幕上天然满足 **长对正 / 高平齐 / 宽相等**（俯↔左靠 45° 辅助线换算）。
`Sheet.tsx` 的 `ProjectionLines` 在悬停零件时画这些连线和 miter 线。

**虚线（不可见轮廓）** 靠**深度剥离**：先渲最前一层，再渲"只在第一层背后"的第二、三层
（`uPass==2` 时 `gl_FragCoord.z <= front + ε` 就 discard），把剥出来的层轮廓断成虚线画出来。
于是被挡住的孔、内腔轮廓自动成为细虚线。

点画线 / 圆的十字中心线来自 `centreLines: [[起点, 终点, 半径?]]`。

## 4. 建模纪律（真正决定成败的地方）

1. **单位统一，坐标固定**：+x 前、+y 上、地面 y=0、对称面 z=0。剖切面固定 z=0。
2. **回转体用 `Turn` 车削**：profile 是 `(半径, 轴向位置)` 闭合轮廓，从轴心出发一圈描外轮廓。
   实心件给外轮廓；**空心/薄壁一定给"外轮廓 + 反向内轮廓"**（`tube()` / `cone()` / `dome()` 是模板）。
   `ccw()` 负责理顺绕向，让"背面 = 材质内侧"这个约定成立，剖切才好看。
3. **折角留硬边**：用尖角，别在建模里倒大圆角。
4. **看不见的不乱建，要讲的一定建**：内部结构不建，剖视里就是空的。
5. **缓存键 `k` 唯一**：`Turn/Plate/Pipe` 按 `k` 缓存几何，同名会串味，一律加机器前缀。
6. **零件 `index` ≤ 31**（ID 通道精度/编号上限）。

## 5. 可读性：拆解、讲解、引线

- **分层拆解**：`PARTS.stage` 给每个零件一个时间窗，按装配逆序 → 拖滑杆就是看拆装过程。
  `explode` 方向朝"真实会拿出去的方向"，图才像真的爆炸图。
- **引线气泡**：每个零件一个 `<Callout>`，`p` 放在朝镜头的表面；导出 PNG 时气泡会径向推开并避让。
- **讲解步骤**：`STEPS` 让人"先看整体 → 再剖开看原理 → 再拆开看结构"，每步可 `focus` 特写。

## 6. 三条"一定"、三条"一定不"

**一定**：
1. 只写**数据 + 几何**，别改渲染器。
2. 把**要剖开讲的内部结构真的建出来**，并放在 z=0 对称处。
3. **逐张看自检截图**，出画就调相机。

**一定不**：
1. 不混用单位、不把对称面挪离 z=0。
2. 不把薄壁件画成实心。
3. 不让多件运动各用各的计时。
